Setup Guide

Follow these steps to initialize your voice server.

1

Clone

Fetch the repository to your local directory.

git clone https://github.com/fellowgeek/mcp-speak.git
2

Dependencies

Install the required Python packages.

pip install -r requirements.txt
3

Verify Path

Find the absolute path to your server script.

/path/to/speak_server.py

Integration

Add SpeakMCP to your agent configuration files.

Gemini CLI Config 
{
  "mcpServers": {
    "voice": {
      "command": "python3",
      "args": ["/ABSOLUTE/PATH/TO/speak_server.py"]
    }
  }
}
Claude CLI Config 
claude mcp add voice python3 -- /ABSOLUTE/PATH/TO/speak_server.py
Claude Desktop Config 
{
  "mcpServers": {
    "voice": {
      "command": "python3",
      "args": ["/ABSOLUTE/PATH/TO/speak_server.py"]
    }
  }
}
